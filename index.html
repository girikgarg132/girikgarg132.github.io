Authoritative Multiplayer & State Sync

Strict 0 Bytes/frame garbage collection allocation policy in Update() and FixedUpdate() loops. Architected with custom generic object pools, struct arrays, avoiding boxing/unboxing, and rigorous verification in the Unity Memory Profiler.
