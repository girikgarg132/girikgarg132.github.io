Platform Overview & Scalability

TMKOC Clubhouse was developed as a comprehensive mobile skill and casual gaming hub for millions of players. The platform required embedding multiple independently developed Unity games seamlessly inside a responsive Flutter host application without causing high memory spikes or lifecycle desynchronizations.

As a lead Unity developer on this platform, I engineered the cross-platform bridge and unified communication layers, scaling the ecosystem to over 15 high-quality game titles across Android and iOS.

Engineering Highlights & Architecture

  • Custom Flutter-Unity Native Bridge: Engineered a robust inter-process communication (IPC) channel between the native Flutter application shell and embedded Unity runtime, managing seamless context passing, player authentication, and state management.
  • Modular Multi-Game Architecture: Designed a decoupled architecture allowing 15+ distinct game titles to be dynamically loaded, initialized, and cleanly unloaded from memory without memory leaks.
  • In-House API & Economy Integration: Integrated proprietary backend APIs for live user profile syncing, wallet balances, match analytics, and anti-tamper security checks.
  • Platform Security & Lifecycle Compliance: Maintained strict adherence to evolving Google Play and Apple App Store compliance guidelines, managing deep background pause/resume events and crash-free OS transitions.

Technical Impact

25% Reduction in Load Times: Optimized asset bundling and dynamic loading routines, reducing time-to-first-frame when launching game sub-modules from the Flutter hub.

Zero Crash Unload Pipeline: Resolved native iOS/Android thread conflicts during Unity engine suspension and resume cycles, ensuring 100% crash-free transitions back to the main Flutter feed.
