Unity Preferences Utility

A visual editor window and automated C# code generator for Unity's PlayerPrefs and EditorPrefs. Organizes project preferences inside version-controlled .prefsdef asset files with strongly-typed properties and support for non-primitive data types.

The Problem: Magic Strings & PlayerPrefs Fragility

Unity's built-in PlayerPrefs and EditorPrefs are standard tools for persisting small settings, game options, and user states. However, standard usage introduces recurring architectural flaws in production codebases:

  • Magic String Vulnerabilities: Accessing preferences requires typing string literals (e.g. PlayerPrefs.GetFloat("User_Sfx_Volume", 1.0f)). A single typo in a key string fails silently, returning the default value with zero compiler warnings or runtime errors.
  • No Central Source of Truth: Keys are scattered across gameplay, UI, audio, and save managers without unified documentation or schema verification.
  • Limited Primitive Types: Standard PlayerPrefs only natively stores int, float, and string. Saving common types such as bool, enum, DateTime, or structured objects requires repetitive boilerplate casts and manual serialization.
  • Opaque In-Editor Inspection: Inspecting or wiping saved values during play mode testing requires either digging into the Windows Registry / macOS plist files or writing custom debug inspector scripts.

Architectural Solution & Key Features

UnityPreferencesUtility solves these pain points by pairing a version-controlled definition asset with automated compile-time C# code generation:

.prefsdef Asset Schema

Define all project preferences, key strings, and default fallback values in a version-controlled .prefsdef asset file that tracks cleanly in Git.

Automated C# CodeGen

Generates clean, strongly-typed static wrapper properties (e.g., GGPlayerPrefs.MasterVolume) with IDE autocomplete and compile-time verification.

Extended Type Support

Natively serializes types not supported by default PlayerPrefs, including bool, custom enums, DateTime, and complex classes.

Visual Editor Inspector

Inspect, edit, and reset active preference values in real time within the Unity Editor under Window > Preferences Utility.

Before vs. After Code Comparison

Eliminating magic strings and type-casting boilerplate replaces error-prone calls with clean, self-documenting C# accessors:

Traditional Error-Prone PlayerPrefs Approach 
// ❌ Scattered magic strings, fragile typing, and manual bool conversion
string volumeKey = "Vol_Sfx_Master";
float sfxVolume = PlayerPrefs.GetFloat(volumeKey, 1.0f);

// Storing a boolean requires manual integer mapping
bool isTutorialDone = PlayerPrefs.GetInt("Tutorial_Completed", 0) == 1;
PlayerPrefs.SetInt("Tutorial_Completed", isTutorialDone ? 1 : 0);
PlayerPrefs.Save();
With UnityPreferencesUtility Code Generation 
//  Strongly-typed, autocomplete-friendly, compile-time verified
float sfxVolume = GGPlayerPrefs.MasterVolume;
GGPlayerPrefs.MasterVolume = 0.85f;

// Native bools, enums, and timestamps without boilerplate
if (!GGPlayerPrefs.CompletedTutorial) 
{
    LaunchTutorialSequence();
    GGPlayerPrefs.CompletedTutorial = true;
}

GGPlayerPrefs.GraphicsQuality = QualityTier.High;
GGPlayerPrefs.LastLoginTime = DateTime.UtcNow;

Installation via Unity Package Manager (UPM)

Install directly into any Unity project using the Unity Package Manager Git dependency:

Unity Package Manager — Git URL 
https://github.com/girikgarg132/UnityPreferencesUtility.git#v1.0.0

Usage Workflow:

  • Open Window > Preferences Utility in the top menu.
  • Create or select your .prefsdef asset file inside your project.
  • Add your desired keys, types (Float, Int, Bool, Enum, String, DateTime), and defaults.
  • Click Generate C# Code — the utility generates strongly-typed wrappers in your chosen scripts folder.
